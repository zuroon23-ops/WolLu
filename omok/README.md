# WolLu 오목 V1.4

## 기능
15×15 오목, 흑백 직접 선택 및 양쪽 READY, 턴당 제한 시간(없음/10/15/30/60/120초), 퍼즈 상호 동의 및 3초 재개, 기권, 재대결, 접속자와 방 목록, 대기실과 게임방 채팅 분리, 모바일 반응형, 기존 60초 재접속 및 빈 방 정리.

## 자체 오목 규칙
흑백 모두 삼삼 및 육목 이상 금지, 사사 허용. 정확히 5목을 연결하면 승리. 삼삼은 한 수로 열린 삼 두 개 이상이 생기는 경우입니다. 열린 삼은 한 수를 추가해 양 끝이 빈 연속 4목을 만들 수 있는 삼이며, 해당 추가 수가 장목이면 제외합니다. 끊어진 삼도 포함하고 같은 삼의 두 완성 위치를 중복 집계하지 않습니다. 정확한 5목은 삼삼보다 우선하지만 다른 방향의 장목이 동시에 발생하면 금지합니다. 금수 착수는 거절하고 시간은 계속 흐릅니다. 정식 렌주룰과 다릅니다. 로컬 대전에도 동일 적용합니다.

## Firebase
- 기존 firebase-config.js를 반드시 유지. Spark 무료 요금제, 익명 인증, 기존 승인 도메인 유지.
- Realtime Database 콘솔 규칙을 `database.rules.json`으로 교체 후 게시.
- 새 경로 `omokV14`를 사용합니다. 구버전 방/채팅은 이전하지 않으며 구버전 경로는 이 규칙에서 차단됩니다.
- 일반 채팅(user): 24시간/100개 표시, 시스템(system): 1시간/30개 표시. 새 입장 이전 메시지는 표시하지 않습니다. 새로고침과 일시적인 연결 끊김은 유지합니다. 접속 중 만료된 데이터 정리. 모든 이용자가 떠나면 정리 시점은 지연될 수 있습니다.
- 채팅 숨김은 UI 표시 정책이며 DB에서 모든 이전 기록의 접근 자체를 막는 보안 정책은 아닙니다. 시스템 메시지와 1초 전송 간격, 금수/승패 판정은 클라이언트 중심으로 구현되어 조작 방지를 보장하지 않습니다. 닉네임 중복 방지·계정·전적은 제외.
