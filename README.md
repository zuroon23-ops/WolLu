# MUGETA

웹 보드게임 플랫폼 시작용 패키지입니다.

- index.html: 게임 선택 메인 홈페이지
- omok/: 기존 오목 게임과 Firebase 설정 파일

압축을 풀어 index.html, README.md, omok 폴더를 GitHub 저장소 루트에 업로드하세요. GitHub Pages는 main / (root)를 사용합니다. 오목의 온라인 기능 설정은 omok/README.md를 참고하세요. 해당 설명서의 저장소 루트 업로드 지시는 기존 독립형 버전 기준이며, MUGETA에서는 오목 파일을 omok/ 폴더 안에 유지합니다. Firebase 미설정 상태에서는 한 기기 대전만 가능합니다.
